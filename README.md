# Credit Risk Dataset: SQL & Python Practice
## О проекте

Этот репозиторий представляет собой учебную практику по анализу данных и отработке технических навыков. Основная цель — закрепление работы с SQL-запросами, визуализацией в Python и предобработкой табличных данных.

Что отработано в рамках проекта:

Очистка данных: удаление дубликатов, обработка пропущенных значений (NaN), фильтрация аномалий.

SQL (PostgreSQL): написание запросов с GROUP BY, CASE WHEN, CTE (WITH), а также использование оконных функций (DENSE_RANK, NTILE).

Python (pandas, matplotlib, seaborn): базовая предобработка данных и построение графиков (barplot, boxplot, анализ распределений).

Расчет метрик: доля дефолтов (default rate), вклад грейдов, ожидаемая доходность.

## Границы проекта:
Данный репозиторий — это учебная практика и отработка синтаксиса.
Здесь не рассматривается углубленная бизнес-аналитика, прогнозное моделирование (ML), сложные финансовые расчеты (LGD/EAD) или интерактивные дашборды.
Более глубокие и комплексные кейсы по анализу данных представлены в моих закрепленных репозиториях (например, IBM HR Analytics).
